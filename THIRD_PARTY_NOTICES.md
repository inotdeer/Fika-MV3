# Credits and license provenance

This is an unofficial Manifest V3 adaptation of [Fika-Chrome](https://github.com/yuiitsu/Fika-Chrome), maintained upstream by yuiitsu with contributions from nil Xinzhou Ye. The original package.json identifies the author as onlyfu and declares ISC. Existing source author comments are retained.

The root LICENSE supplies the standard ISC text based on that declaration. It was added for this adaptation, not copied from an upstream LICENSE file; the supplied archive contained none. The attribution line is assembled from the original author declaration and project credits, without inventing a copyright year. The adaptation's code changes are distributed under ISC as well. Third-party components retain their separate licenses.

Font copyright, license and reserved-name declarations were extracted directly from all eight bundled TTF files. Fonts are unchanged. The Merriweather notice uses the bundled files' 2016 attribution, with the standard OFL text. Open Sans's embedded attribution is retained verbatim in Font-embedded-notices.txt.

License text sources: https://raw.githubusercontent.com/jquery/jquery/1.11.0/MIT-LICENSE.txt ; https://raw.githubusercontent.com/highlightjs/highlight.js/main/LICENSE ; https://www.apache.org/licenses/LICENSE-2.0.txt ; https://raw.githubusercontent.com/google/fonts/main/ofl/merriweather/OFL.txt . highlight.js's bundled header declares BSD3; the full text comes from the project's current license, which credits Ivan Sagalaev.

jQuery has been modified to remove obsolete runtime code generation; its original banner remains. highlight.js is unchanged. Original Fika branding and graphics are retained with upstream credit; this adaptation does not claim ownership of them or endorsement by the upstream developers.
